# 学习笔记

按真实课程或问题建立笔记，优先记录理解与排错过程，不复制大段课程内容。

建议命名：`01-实际主题.md` 或 `YYYY-MM-DD-问题说明.md`。

每篇笔记可按需包含：

1. 课程或问题来源。
2. 本节目标和关联脚本、场景、资源。
3. 自己的理解与最小示例。
4. 误解、现象、原因和修正方式。
5. 验证步骤、实际结果和证据来源。
6. 仍待确认的边界与一个最小下一步。

ScriptableObject 练习应特别记录：引用了哪个资源、是否共享、修改了什么、停止后再次运行的结果，以及是否检查实际资源差异。

尚无验证结果的部分写“待验证”，不预填成功结论。
