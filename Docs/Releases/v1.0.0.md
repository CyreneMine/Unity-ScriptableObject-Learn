# SingleScriptableObject v1.0.0：可独立导入的泛型数据访问基类

从 ScriptableObject 学习工程中整理最后的泛型单例式访问基类，保留原有实现，方便下载后导入其他 Unity 项目。

## 下载

- `SingleScriptableObject-1.0.0.unitypackage`：推荐，使用 `Assets > Import Package > Custom Package` 导入。
- `SingleScriptableObject-1.0.0.zip`：源码与元数据，将其中 `Assets/SingleScriptableObject` 复制到自己的项目。
- `verification-result.json`：临时工程的实际 Unity 验证报告。
- `SHA256SUMS.txt`：以上附件的 SHA256 校验和。

两种包只需选择一种。包内仅包含基类、元数据和中文使用说明，无第三方资源或额外包依赖。

## 用法

子类以自身为泛型参数继承 `SingleScriptableObject<T>`，例如 `EnemyConfig : SingleScriptableObject<EnemyConfig>`。

将 `EnemyConfig.asset` 放在 `Assets/Resources/ScriptableObject/`，再通过 `EnemyConfig.Instance` 访问。

首次访问优先加载 `Resources/ScriptableObject/类型名`，缺失时创建运行时实例，之后复用缓存。完整示例见包内 README。

## 实际验证

使用 Windows 上的 Unity `6000.3.10f1`，在独立临时工程中导入发布的 unitypackage 并编译，实际检查全部通过：

- 导入脚本与原始源文件 SHA256 相同。
- 已有资源被正确加载，字段值正确。
- 同类型多次访问得到同一个对象。
- 缺失资源时创建非资源文件的运行时实例。
- 兜底实例被缓存，不同泛型类型相互隔离。

## 边界

- 保留原始全局类名，项目中只保留一份此基类。
- 加载失败会创建实例，因此路径错误可能表现为拿到默认值；资源文件名需与类型名一致。
- 不自动持久化玩家修改，不包含 JSON 存档或 Addressables。
- 需要 Unity 主线程；未加入关闭 Domain Reload 后的静态缓存重置。
- 验证范围为上述 Unity 版本的编辑器导入与访问行为；未进行其他版本、平台或独立 Player 验证。

基类源码与课程项目、分阶段复盘文档一同保留在仓库；本次发布没有把教学示例包装成完整游戏框架。
